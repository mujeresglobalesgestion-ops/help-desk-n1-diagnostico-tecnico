# DIAG-001 — Rendimiento lento en Windows

**Tipo:** procedimiento de laboratorio para formación N1. **Estado:** preparado, pendiente de ejecución en un equipo de práctica.

## Objetivo
Identificar síntomas de lentitud y recopilar evidencias básicas sin realizar cambios de riesgo.

## Requisitos
Equipo Windows propio o autorizado. No utilizar equipos empresariales sin permiso.

## Procedimiento
1. Anotar versión de Windows, fecha, síntoma y aplicaciones afectadas; evitar números de serie y datos personales en evidencias públicas.
2. Abrir **Administrador de tareas** con `Ctrl + Shift + Esc`.
3. En **Procesos** y **Rendimiento**, observar CPU, memoria y disco durante la lentitud. Registrar valores medidos, no estimaciones.
4. Abrir **Configuración > Sistema > Almacenamiento** y comprobar espacio disponible.
5. Registrar si el problema ocurre con una aplicación concreta o con todo el sistema.
6. Consultar el historial de actualizaciones solo para contextualizar; no desinstalar actualizaciones ni modificar servicios.
7. Comparar las observaciones con el síntoma y proponer siguiente paso autorizado.

## Interpretación y escalamiento
Un uso elevado de recursos **no demuestra por sí solo** la causa raíz. Escalar ante errores de disco, sospecha de malware, permisos insuficientes o persistencia del problema tras verificaciones aprobadas.
